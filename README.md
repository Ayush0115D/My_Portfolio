# 🚀 3D Developer Portfolio

A modern and interactive developer portfolio built with **React**, **Three.js**, **React Three Fiber**, **GSAP**, and **Tailwind CSS**.

Designed to create an immersive user experience, this portfolio combines smooth animations, interactive 3D elements, and a clean interface to showcase my projects, skills, and experience. Every section is crafted to reflect both creativity and technical expertise while ensuring a fast, responsive, and seamless browsing experience.

## ✨ Features

- Interactive 3D hero section
- Smooth GSAP animations
- Responsive design
- Project showcase
- Experience timeline
- Contact form with EmailJS

## 🛠️ Tech Stack

- **React** – Builds a fast, component-based user interface with reusable components.
- **Vite** – Provides lightning-fast development, HMR, and optimized production builds.
- **Three.js** – Powers immersive 3D graphics and interactive scenes in the browser.
- **React Three Fiber** – Seamlessly integrates Three.js into React using declarative components.
- **GSAP** – Delivers smooth, high-performance animations and scroll-based interactions.
- **Tailwind CSS** – Enables rapid development with a modern, responsive utility-first styling approach.
- **EmailJS** – Handles contact form submissions directly from the frontend without a backend.

## ⚙️ Getting Started

```bash
# Clone the repository
git clone https://github.com/your-username/3d-portfolio.git

# Navigate to the project
cd 3d-portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```
🚀 Deployment

This project is built with Vite and can be deployed to Vercel

To generate the production build - npm run build

To preview the production build locally - npm run preview
